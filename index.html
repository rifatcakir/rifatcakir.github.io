    open source

    spring-ai-test-tools

    Record a real model interaction once, commit it, and replay it in under a millisecond on every run. It works at Spring AI's level, above HTTP, so the code under test does not change.

    • Tool calls replay their recorded results without running the real method.
    • Streaming replays chunk by chunk, tool-call fragments included.
    • Structured output and embeddings are cached by their exact request.
    • Spring AI's own evaluators run deterministically in CI.
    • Replay-only mode turns a missing recording into a failed build.
